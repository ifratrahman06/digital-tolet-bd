Digital To-Let Next.js folder structure

📦 digital-to-let/ Project root
├─ 📁 app/ Next.js App Router — all routes live here
├─ 📁 (auth)/ Route group — auth pages (no shared layout)
├─ 📄 login/page.tsx route
└─ 📄 verify-otp/page.tsx route
├─ 📁 (main)/ Route group — shared navbar/footer layout
├─ 📄 page.tsx Home — search + property listing
├─ 📁 properties/
├─ 📄 page.tsx Browse / filter all listings
└─ 📁 [id]/
└─ 📄 page.tsx Single property detail view
├─ 📄 post-ad/page.tsx route Owner — create new listing
├─ 📄 my-ads/page.tsx route Owner — manage own listings
└─ 📄 profile/page.tsx route
├─ 📁 api/ Next.js API Routes (REST endpoints)
├─ 📁 auth/
├─ 📄 send-otp/route.ts route
└─ 📄 verify-otp/route.ts route
├─ 📁 properties/
├─ 📄 route.ts GET all / POST new
└─ 📁 [id]/
├─ 📄 route.ts GET / PATCH / DELETE by id
└─ 📄 toggle-status/route.ts PATCH — Available ↔ Rented
└─ 📄 upload/route.ts POST — Cloudinary image upload
├─ 📄 layout.tsx Root layout — fonts, providers, metadata
├─ 📄 globals.css
└─ 📄 not-found.tsx
├─ 📁 components/ Reusable UI components (client-side)
├─ 📁 layout/
├─ 📄 Navbar.tsx comp
└─ 📄 Footer.tsx comp Developer credits & social links
├─ 📁 property/
├─ 📄 PropertyCard.tsx comp
├─ 📄 PropertyGrid.tsx comp
├─ 📄 ImageGallery.tsx comp
├─ 📄 NearbyPlaces.tsx comp Bus / Mosque / Market / Hospital
└─ 📄 StatusToggle.tsx comp Available ↔ Rented toggle
├─ 📁 search/
├─ 📄 SearchBar.tsx comp
└─ 📄 FilterChips.tsx comp Category / budget / facility filters
├─ 📁 forms/
├─ 📄 PostAdForm.tsx comp
└─ 📄 OtpForm.tsx comp
└─ 📁 ui/ Primitive atoms — Button, Badge, Input, Modal…
├─ 📁 lib/ Non-UI utilities & integrations
├─ 📄 db.ts util MongoDB + Mongoose connection singleton
├─ 📄 cloudinary.ts util Cloudinary SDK config & upload helper
├─ 📄 auth.ts util OTP generation, session helpers
├─ 📄 validations.ts util Zod schemas for forms & API input
└─ 📄 utils.ts util formatPrice, cn(), date helpers…
├─ 📁 models/ Mongoose schemas (Step 2)

├─ 📄 property.ts IProperty, ILocation, IFacilities…
└─ 📄 user.ts IUser, Role enum
├─ 📁 hooks/
├─ 📄 useProperties.ts Fetch + filter properties (SWR/React Query)
└─ 📄 useAuth.ts Current user session state
├─ 📁 public/
├─ 🖼️ logo.svg
└─ 📁 images/ Static fallback images
├─ 📄 .env.local MONGODB_URI, CLOUDINARY_*, NEXTAUTH_SECRET
├─ 📄 next.config.ts
├─ 📄 tailwind.config.ts
└─ 📄 tsconfig.json
